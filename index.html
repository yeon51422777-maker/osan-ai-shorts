자막 넣고 내 자막 모양 저장하기

  1. 텍스트 → 텍스트 추가 → 문구 입력
  2. 글꼴에서 굵은 글씨 고르기 (모르겠으면 프리텐다드)
  3. 스타일 → 테두리(획) 두께 11~13 → 글자 사이 좁히기
  4. 두 손가락으로 크기 조절, 화면 가운데~살짝 아래에 두기
  5. 다음 자막은 첫 자막을 복사해서 뒤로 옮기고 글만 바꾸기
